# YUNGRØC / RøcAudio landing page

This is a static, responsive landing page for YUNGRØC / RøcAudio. Edit service names and descriptions in `content.js`; the main page copy is in `index.html`, and visual styles are in `styles.css`.

## Before deployment

1. If you use a custom domain, update the canonical URL and `og:url` in `index.html`, plus the sitemap address in `robots.txt` and `sitemap.xml`.
2. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. The included workflow publishes the site after each push to `main`.

The email and phone links are ready to use. No backend or build step is required.
